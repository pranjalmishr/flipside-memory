# FlipSide 1.0 — release notes

Released 13 November 2026.

- **Public game:** https://flipside-memory.vercel.app
- **Private source:** https://github.com/pranjalmishr/flipside-memory
- **Vercel project:** `flipside-memory`, in the existing `pranjal-mishras-projects-52970ad6` Hobby team.
- **Production branch:** `main`; GitHub repository connected to Vercel.

## Polish and fixes

- Locally bundled, licensed variable fonts replace a blocking third-party font request. No font/image/music/runtime requests leave the application's origin.
- Phone Play/Restart brings the playing area into view. Active desktop rounds use a compact header and a viewport-bounded card grid so all cards fit at the tested laptop/desktop dimensions.
- Increased major control targets to 44 px, made difficulty tiles full hit targets, improved small-label readability, and corrected text contrast in Daydream and Sunset, result bonuses, and leaderboard stars. All skins retain their own consistent tokens.
- Preserved keyboard focus when shuffling. Holding P/H/S no longer repeatedly toggles pause or consumes limited power-ups.
- Invalid/mixed-type card indexes cannot bypass duplicate-flip protection.
- A delayed victory dialog cannot replace a leaderboard the player has already opened.
- Cancelling/restarting/pausing cancels queued and sounding effects; partial/closed audio contexts fail softly instead of breaking controls or leaving music schedulers running.
- Long-running timer displays fit narrow phones. Existing score, star, timer, hint, shuffle, saved-state, audio, and leaderboard behavior remains covered by regression tests.
- Added a pinned package lock, static production allow-list build, GitHub Actions verification, Vercel security headers, and exclusions for local environment files, tooling, tests, and artifacts.

## Re-run

```sh
npm ci
npm test
npm run build
npx playwright install chromium firefox webkit
# Start a preview in another terminal:
SERVE_DIR=dist npm run dev
BROWSER_CHANNEL=chromium npm run test:browser

# Public-site release checks:
GAME_URL=https://flipside-memory.vercel.app PRODUCTION_CHECKS=1 npm run test:release
```

GitHub Actions runs the complete test/build/browser pipeline on pushes and pull requests. Vercel builds connected `main` pushes independently. Check both systems before declaring a future release verified.

## Data and operational boundaries

- Personal progress, preferences, and top scores remain browser-local, scoped to the host. Local preview data does not migrate automatically to the public hostname.
- One active save is shared by tabs on the same origin; play one tab at a time.
- Blocked/quota-limited storage warns and falls back to current-tab memory. A local leaderboard is editable personal data, not a verified online competition.
- Unfinished card/hint reveals close after reload; spent power-ups and completed attempts remain counted. Restored rounds open paused and exclude time away.
- No accounts, analytics, paid backend, plan upgrade, or billing changes were added. Unrelated workspace applications were not modified.
